VISÃO GERAL

Sobre o projeto

O SquadHub é uma plataforma desenvolvida com o objetivo de facilitar a busca por jogadores e a formação de grupos para partidas online.

A proposta é centralizar a descoberta de jogadores e lobbies em uma única interface, permitindo que o usuário encontre partidas de maneira simples e rápida.

UI / UX

Decisões de interface

Interface minimalista

A interface utiliza poucos elementos por tela para manter o foco nas principais ações do usuário.

Hierarquia visual

Cores, tamanhos e espaçamentos são utilizados para destacar as ações mais importantes.

Identidade gamer

O uso de contrastes, gradientes e elementos luminosos reforça a proposta da plataforma.
